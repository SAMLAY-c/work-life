# Changelog

All notable changes to the "Claude Code Skills" plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-19

### Added
- Initial release
- Claude API and CLI integration
- Skill management system
- Real-time progress tracking
- File selection modal
- Excalidraw support
- Custom skill creation
- Settings UI
- Keyboard shortcuts (Ctrl+Shift+C/S/E)

### Features
- One-click AI content generation
- Multiple skill support (diagrams, mindmaps, summaries)
- Automatic file opening
- Progress bar in status bar
- Output folder selection
- Prompt template variables

### Technical
- TypeScript implementation
- esbuild for bundling
- Modular architecture
