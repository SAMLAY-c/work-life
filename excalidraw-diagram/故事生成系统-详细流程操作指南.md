## 产品经理阶段

### 1.1 接收用户需求

**输入格式示例：**
```
用户提示词：一个勇敢的兔子拯救森林的故事
```

**任务：**
- 分析用户需求的核心要素
- 明确故事类型、目标受众、风格偏好
- 识别关键角色和核心冲突

### 1.2 生成创意方案

**提示词模板：**
```
你是一位经验丰富的产品经理。基于以下用户需求，请生成一个详细的创意方案：

用户需求：[用户提示词]

请输出以下内容：
1. 故事核心概念（1-2句话概括）
2. 目标受众分析
3. 风格定位（温馨/冒险/教育等）
4. 核心冲突设计
5. 故事亮点和创新点
6. 预估时长（3-5分钟短视频）
```

**输出示例：**
```markdown
# 创意方案 - 勇敢的兔子拯救森林

## 故事核心概念
一只体型娇小但内心勇敢的兔子，在面对森林危机时，用智慧和勇气带领大家保卫家园。

## 目标受众
- 主要受众：5-10岁儿童
- 次要受众：亲子家庭

## 风格定位
- 温馨治愈
- 冒险励志
- 色彩明亮

## 核心冲突
贪婪的开发商想要砍伐森林建造工厂，小兔子团结森林动物们共同对抗。

## 故事亮点
- 以弱胜强的正能量主题
- 强调团结协作的力量
- 环保意识的潜移默化
```

### 1.3 创建任务分配文档

**提示词模板：**
```
基于以上创意方案，请生成一份详细的任务分配文档，包括：
1. 编剧任务清单
2. 分镜师任务清单
3. AI绘画师任务清单
4. 动画师任务清单
5. 各阶段时间节点
6. 交付物标准
```

**交付物：**
- [ ] 创意方案文档 (PRD)
- [ ] 任务分配文档
- [ ] 项目时间表

## 编剧阶段

### 2.1 故事大纲创作

**输入：**
- 产品经理提供的创意方案

**提示词模板：**
```
你是一位专业的儿童故事编剧。基于以下创意方案，请创作一个完整的故事大纲：

创意方案：
[粘贴产品经理的创意方案]

请输出：
1. 故事梗概（200字）
2. 角色列表（3-5个主要角色）
3. 三幕式结构：
   - 第一幕：开端（介绍主角和背景）
   - 第二幕：发展（冲突升级）
   - 第三幕：高潮与结局（解决冲突）
4. 每个幕的关键情节点（3-5个）
5. 对白要点
```

**输出示例：**
```markdown
# 故事大纲 - 小兔子的森林保卫战

## 故事梗概
在一片宁静的森林里，住着一只叫小白的兔子。当得知开发商要砍伐森林时，胆小的小白挺身而出，团结森林里的动物朋友们，用智慧和勇气成功保卫了家园。

## 角色列表
1. **小白** - 主角，一只胆小但善良的兔子
2. **熊大叔** - 森林里最强壮的动物，一开始不信任小白
3. **松鼠妹妹** - 机灵的侦察兵
4. **猫头鹰博士** - 智慧的顾问
5. **开发商** - 反派，贪婪的商人

## 第一幕：开端
情节点1：小白在森林里快乐地生活
情节点2：发现"即将砍伐"的告示牌
情节点3：召集动物们开会，大家陷入恐慌
情节点4：小白鼓起勇气提出对抗计划
情节点5：熊大叔质疑小白的能力

## 第二幕：发展
情节点1：小白组织动物们分工准备
情节点2：松鼠妹妹侦察到开发商的行动计划
情节点3：猫头鹰博士制定应对策略
情节点4：第一次成功阻止伐木队
情节点5：开发商加大力度，带来更多设备

## 第三幕：高潮与结局
情节点1：最终对抗，开发商派出大批工人
情节点2：动物们团结一致，用各种方法阻碍施工
情节点3：小白用自己的方式感化了部分工人
情节点4：环保部门介入调查
情节点5：开发商放弃计划，森林恢复宁静
```

### 2.2 角色设定生成

**提示词模板：**
```
基于故事大纲，请为每个角色创建详细的角色设定：

角色：[角色名称]

请提供：
1. 基本信息（姓名、年龄、种族）
2. 外貌特征（体型、毛色、穿着）
3. 性格特点（3-5个关键词）
4. 背景故事（100字）
5. 行为动机
6. 特殊技能或能力
7. 经典台词
```

**输出示例：**
```markdown
# 角色设定 - 小白

## 基本信息
- 姓名：小白
- 年龄：2岁（相当于人类的8岁）
- 种族：垂耳兔

## 外貌特征
- 体型：娇小，只有普通兔子的一半大小
- 毛色：雪白色，耳朵尖端有一撮灰色
- 眼睛：大大的红色眼睛，充满好奇
- 穿着：戴着一条蓝色的小围巾

## 性格特点
- 胆小但善良
- 善于观察
- 坚持不懈
- 富有同情心
- 勇于担当

## 背景故事
小白从小体型就比其他兔子小，因此经常被保护。这让他养成了胆小的性格，但也让他更善于观察和思考。当家园受到威胁时，小白第一次站出来保护大家。

## 行为动机
保护森林和朋友们，不想失去美丽的家园。

## 特殊技能
- 敏锐的听觉
- 快速的反应能力
- 擅长制定计划

## 经典台词
"虽然我很小，但我有一颗大大的心！"
```

```

```

**输出示例：**
```markdown
# 人物关系图

## 小白 的关系网

- **关系性质**：亲密的伙伴
- **互动模式**：松鼠妹妹是小白的眼睛和耳朵
- **关键事件**：松鼠妹妹及时通风报信，挽救了大家

### 与猫头鹰博士
- **关系性质**：师徒关系
- **互动模式**：猫头鹰博士指导小白，小白提供行动力
- **关键事件**：猫头鹰博士教给小白"智慧比力量更重要"

### 与开发商
- **关系性质**：对抗关系
- **冲突核心**：保护家园 vs 破坏森林
- **关系转变**：小白用善良感化部分工人
```

**交付物：**

## 分镜师阶段

### 3.1 分镜脚本设计

**输入：**
- 编剧提供的故事大纲
- 角色设定
- 人物关系图

**提示词模板：**
```
你是一位专业的分镜师。基于以下故事大纲，请设计详细的分镜脚本：

故事大纲：
[粘贴故事大纲]

角色设定：
[粘贴角色设定]

请创建分镜脚本，每个镜头包含：
1. 镜头编号（SC001, SC002...）
2. 镜头类型（远景/全景/中景/近景/特写）
3. 画面描述（详细视觉描述）
4. 运镜方式（固定/推/拉/摇/移/跟）
5. 时长（秒）
6. 对白/旁白
7. 音效/音乐提示

总共需要 [30-50] 个镜头，视频总时长约 [3-5] 分钟。
```

**输出示例：**
```markdown
# 分镜脚本 - 小兔子的森林保卫战

## 第一幕

### SC001
- **镜头类型**：远景
- **画面描述**：阳光明媚的森林全景，树木郁郁葱葱，鸟语花香
- **运镜方式**：缓慢推镜头
- **时长**：5秒
- **旁白**：在一片美丽的森林里，住着许多快乐的小动物
- **音乐**：轻快温馨的背景音乐

### SC002
- **镜头类型**：全景
- **画面描述**：小白在草地上跳跃，阳光洒在白色毛发上
- **运镜方式**：跟随镜头
- **时长**：3秒
- **音乐**：音乐继续

### SC003
- **镜头类型**：中景
- **画面描述**：小白停下脚步，耳朵动了动，注意到前面的告示牌
- **运镜方式**：固定镜头
- **时长**：4秒
- **音效**：鸟叫声突然停止
- **对白**（小白）："嗯？那是什么？"

### SC004
- **镜头类型**：特写
- **画面描述**：告示牌特写，写着"即将施工 - 森林开发项目"
- **运镜方式**：推镜头
- **时长**：3秒
- **音效**：紧张的音乐渐入
- **旁白**：直到有一天，森林面临了前所未有的危机...

[继续其他镜头...]
```

## AI绘画师阶段

### 4.1 角色设计图生成

**输入：**
- 角色设定文档
- 视觉风格指南

**工具：** Midjourney / Stable Diffusion / Flux

**Midjourney 提示词模板：**
```
基于以下角色设定，生成 Midjourney 提示词：

角色名称：[角色名称]
角色设定：[粘贴角色设定]
视觉风格：[粘贴视觉风格指南]

请生成：
1. 英文提示词（Midjourney 格式）
2. 中文说明
3. 参数建议
```

**示例输出：**
```markdown
# 角色设计图 - 小白

## Midjourney 提示词

### 主设计图
**提示词：**
```
A cute little white rabbit character, lop ears with gray ear tips, wearing a small blue scarf, big red eyes, Pixar style 3D render, round and cute design, soft white fur texture, sunny forest background, bright natural lighting, high quality, detailed --ar 1:1 --niji 6
```

**中文说明：**
- 一只可爱的白色小兔子角色
- 垂耳，耳尖有灰色
- 戴着蓝色小围巾
- 大大的红色眼睛
- 皮克斯风格 3D 渲染
- 圆润可爱的设计
- 柔软的白色毛发质感
- 阳光明媚的森林背景
- 明亮的自然光
- 高质量细节

**参数：**
- `--ar 1:1`：正方形画幅
- `--niji 6`：使用 Niji 模型（适合动漫风格）

### 表情包组
**提示词：**
```
Character sheet of a cute white rabbit, multiple expressions including happy, sad, brave, scared, surprised, Pixar style 3D render, white background, clean layout --ar 3:2 --niji 6
```

### 动作姿势组
**提示词：**
```
A cute white rabbit character in different poses - jumping, running, standing bravely, hiding behind a tree, Pixar style 3D render, white background, character design sheet --ar 16:9 --niji 6
```
```

**操作步骤：**
1. 复制提示词到 Midjourney
2. 生成多版本选择
3. 使用 Upscale 放大优选图像
4. 保存到项目文件夹：`/assets/characters/小白/`
5. 命名规范：`小白_主设计图_v1.png`

## 常见问题与解决方案

### Q1: AI 生成的图片风格不统一怎么办？
**A:**
- 在提示词中固定风格描述词
- 使用 Seed 值保持一致性
- 使用 ControlNet 控制构图
- 后期统一调色

### Q2: 视频片段之间风格差异大怎么办？
**A:**
- 统一所有提示词中的风格描述
- 使用相同的模型和参数
- 后期统一调色处理

### Q3: 动画效果不理想怎么办？
**A:**
- 尝试不同工具（Runway/Pika/Sora）
- 调整提示词，细化动作描述
- 使用图生视频功能
- 考虑结合传统动画软件

### Q4: 配音不自然怎么办？
**A:**
- 尝试多个 TTS 工具
- 调整语速、音调参数
- 考虑真人配音
- 使用 AI 语音克隆工具

### Q5: 项目文件太大如何管理？
**A:**
- 建立清晰的文件夹结构
- 定期清理不需要的素材
- 使用云存储备份
- 压缩存档旧版本
