## 📚 Remotion Skills 完整使用教程

### 一、什么是 Remotion Skills?

Remotion Skills 是一套"AI 知识包",让 Claude Code 学会如何正确写 Remotion 代码。这些技能对 AI 代理如 Claude Code、Codex 或 Cursor 非常有用。

**核心价值:**

- 🎯 让 AI 理解 Remotion 的最佳实践
- 🚀 避免常见错误(如动画参数顺序、帧数计算等)
- 📦 包含 30+ 个规则文件,涵盖动画、音频、3D、字幕等

---

### 二、环境准备

#### 1. 安装必要工具

```bash
# 确保 Node.js 版本 >= 18
node -v

# 如果版本低于 18,使用 nvm 更新
nvm install 18
nvm use 18
```

#### 2. 安装 Claude Code

Claude Code 需要付费订阅。访问 [claude.ai/code](https://claude.ai/code) 注册并安装。

---

### 三、创建 Remotion 项目(两种方式)

#### 方式 1:自动安装 Skills(推荐)

```bash
# 创建项目时自动安装
npx create-video@latest my-video

# 选择配置:
# - Template: blank
# - TypeScript: Yes
# - TailwindCSS: Yes
# - Install Skills: Yes  👈 关键选项!
```

#### 方式 2:手动安装 Skills

```bash
# 1. 先创建项目
npx create-video@latest my-video

# 2. 进入项目
cd my-video

# 3. 安装 Remotion Skills
npx skills add remotion-dev/skills --skill remotion-best-practices
```

Skills 会安装到项目的 `.claude/skills` 目录。

---

### 四、启动项目

```bash
# 1. 启动 Remotion 预览服务器
npm run dev

# 浏览器会打开 http://localhost:3000
# 这是实时预览界面,改代码立刻能看到效果

# 2. 新开一个终端,启动 Claude Code
cd my-video
claude
```

### 五、验证 Skills 是否生效

仅仅安装了 Skill 不代表 Claude 正在使用它。用以下方法测试:

#### 测试问题:

```
"在 Remotion 中如何创建平滑的淡入效果?"
```

Claude 会提到 `interpolate()` 和 `useCurrentFrame()`,这是 Remotion 的标准方法。

如果 Claude 没自动加载,可以手动指定:

```

或者
"使用 Remotion 最佳实践,创建一个淡入动画"
```

### 六、实战案例:创建 10 秒产品发布视频

#### 1. 描述需求(自然语言)

在 Claude Code 中输入:

```
创建一个 10 秒的产品发布视频:

场景 1 (0-3秒):
- 深色背景
- 产品名称 "DevFlow" 从透明淡入
- 加发光效果

场景 2 (3-7秒):
- 产品名称滑到左边
- 右边依次出现 3 个特性:
  1. "⚡ 10x Faster"
  2. "🔒 Enterprise Security"
  3. "🌍 Global CDN"

场景 3 (7-10秒):
- 全部元素淡出
- CTA 按钮 "Get Started" 放大出现
- 加脉冲动画
```

#### 2. Claude 自动生成文件结构

```
src/
├── ProductLaunch/
│   ├── index.tsx        # 主组件
│   ├── Intro.tsx        # 场景 1
│   ├── Features.tsx     # 场景 2
│   └── CTA.tsx          # 场景 3
└── Root.tsx             # 注册 Composition
```

#### 3. 生成的代码示例

```tsx
// src/ProductLaunch/index.tsx
import { AbsoluteFill, Sequence } from 'remotion';
import { Intro } from './Intro';
import { Features } from './Features';
import { CTA } from './CTA';

export const ProductLaunch: React.FC = () => {
  return (
    <AbsoluteFill className="bg-slate-900">
      {/* 场景 1: 0-90 帧 (3秒) */}
      <Sequence from={0} durationInFrames={90}>
        <Intro />
      </Sequence>
      
      {/* 场景 2: 90-210 帧 (4秒) */}
      <Sequence from={90} durationInFrames={120}>
        <Features />
      </Sequence>
      
      {/* 场景 3: 210-300 帧 (3秒) */}
      <Sequence from={210} durationInFrames={90}>
        <CTA />
      </Sequence>
    </AbsoluteFill>
  );
};
```

#### 4. 实时预览 & 迭代

打开 `http://localhost:3000` 查看效果。

**不满意?继续用自然语言调整:**

```
"发光效果太强了,减弱 50%"
"特性出现的间隔改成 0.5 秒"
"CTA 按钮换成蓝色"
```

#### 5. 渲染输出

```bash
npx remotion render ProductLaunch out/product-launch.mp4
```

### 八、进阶技巧

#### 1. 批量生成视频

```tsx
// 参数化组件
export const PersonalizedVideo: React.FC<{
  userName: string;
  productName: string;
}> = ({ userName, productName }) => {
  return (
    <AbsoluteFill>
      <h1>Hi {userName}, meet {productName}</h1>
    </AbsoluteFill>
  );
};
```

批量渲染脚本:

```typescript
const users = [
  { userName: 'Alice', productName: 'DevFlow' },
  { userName: 'Bob', productName: 'DevFlow' },
  // ... 1000 个用户
];

for (const user of users) {
  await renderMedia({
    composition: 'PersonalizedVideo',
    inputProps: user,
    outputLocation: `out/${user.userName}.mp4`,
  });
}
```

#### 2. 保持简单

从测试中学到的最重要经验:保持简单。当你尝试做复杂的事情——很多移动元素、重叠动画、花哨转场——很快就会变得混乱。

**建议:**

- ✅ 从简单动画开始(文字淡入、滑动)
- ✅ 逐步迭代增加效果
- ❌ 不要一次做太多复杂效果
