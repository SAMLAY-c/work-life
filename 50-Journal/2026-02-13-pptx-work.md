# PPT 渐变组件开发总结

## 项目概述

本日在 `F:\github\skill\ppt` 项目中完成了 PPT 渐变组件功能的实现，解决了 html2pptx 库不支持 CSS 渐变的限制，通过预渲染 PNG 图片的方式实现了渐变效果在 PowerPoint 中的应用。

---

## 核心问题

### 问题背景

- **html2pptx 限制**: 不支持 CSS `linear-gradient()` 函数
- **DIV 背景图片限制**: html2pptx 不支持 `background-image` 在 DIV 元素上
- **Windows 路径问题**: pptxgenjs 在 Windows 上处理路径时存在双盘符前缀 bug

### 解决方案

使用 **Sharp** 库将 SVG 渐变预渲染为 PNG 图片，然后通过 PptxGenJS 直接添加到幻灯片中。

#### 支持的渐变类型

| 类型 | 用途 | 输出文件 |

| 线性渐变 | 装饰条、背景 | `cyan-horizontal-bar.png`, `deep-blue-bg.png` |
| 方形渐变 | 卡片背景 | `gradient-box-50.png`, `gradient-box-60.png` |

#### 核心代码逻辑

```javascript
// 创建 SVG → 转换为 PNG
async function createCircleGradient(name, config) {
  const svg = `<svg><defs><radialGradient>...</radialGradient></defs>...</svg>`;
  await sharp(Buffer.from(svg)).png().toFile(`assets/${name}.png`);
}

async function createLinearGradient(name, config, direction) {
  const svg = `<svg><defs><linearGradient>...</linearGradient></defs>...</svg>`;
  await sharp(Buffer.from(svg)).png().toFile(`assets/${name}.png`);
}
```

## 技术细节

### 图片预渲染原理

```
SVG (渐变定义) → Sharp (PNG 编码) → 文件系统 → PptxGenJS (添加到 PPT)
```

### 为什么不能用 CSS 渐变？

1. html2pptx 解析 HTML 时忽略 `background-image`
2. `linear-gradient()` 函数不被识别
3. 即使支持，pptxgenjs 最终也需要转换为图片或纯色

### Windows 路径问题解决

```javascript
// ❌ 错误: F:/github/skill/ppt/test/workspace/assets/cyan-dot.png
// 会被解析为 F:\F:\github\...

// ✅ 解决: 复制到当前目录，使用相对路径
cp assets/*.png .
slide.addImage({ path: 'cyan-dot.png', ... })
```
