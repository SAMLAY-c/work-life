由于 `npm install` 超时，我们必须先解决这个问题，才能让代码跑起来。

以下是接下来的**标准操作步骤**（请按顺序执行）：

### 第一步：解决 npm 超时并安装依赖

你在国内/亚洲地区，直接连接 npm 官方源经常会超时。我们需要临时切换到淘宝镜像源来安装。

请在终端（Terminal）逐行执行以下命令：

```bash
# 1. 设置 npm 镜像源为国内镜像（提速）
npm config set registry https://registry.npmmirror.com

# 2. 再次尝试安装依赖（这次应该会很快）
npm install

# 3. 顺便确保安装了 Sanity 相关的核心库（防止 package.json 没写全）
npm install next-sanity @sanity/client @sanity/image-url react-portable-text
```

### 第二步：配置环境变量

我在你的截图中看到了 Project ID 是 `h8272qgq`。我们需要把这个告诉你的代码。

请在你的项目根目录下，创建一个名为 `.env.local` 的文件（如果已有，就追加内容），填入以下内容：

```bash
# .env.local

# Next.js 前端用的
NEXT_PUBLIC_SANITY_PROJECT_ID=h8272qgq
NEXT_PUBLIC_SANITY_DATASET=production

# Sanity Studio 后台用的 (如果有独立文件夹)
SANITY_STUDIO_PROJECT_ID=h8272qgq
SANITY_STUDIO_DATASET=production
```

### 第一步：清理旧战场 (必做)

为了防止 npm 和 pnpm 冲突，先清理掉刚才失败的残留文件。在终端运行：

codeBash

```
# 删除 node_modules 和 lock 文件
rm -rf node_modules package-lock.json
# Windows 用户如果命令报错，手动在文件夹里删掉这两个文件/文件夹即可
```
