# 飞书卡片回调与权限控制完整方案

> 场景：SDR 转交客户卡片 → 指定销售点击确认 → 自动更新多维表格

---

## 🎯 整体架构

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  飞书多维表格 │ ───▶ │  你的后端    │ ───▶ │  发送卡片    │
│  (Base)     │      │  (Python/JS) │      │  (给指定人)  │
└─────────────┘      └──────┬──────┘      └──────┬──────┘
     ▲                      │                     │
     │                      │                     │
     │                      ▼                     │
     │              ┌─────────────┐               │
     │              │ 权限校验通过 │               │
     │              │ 更新表格状态 │               │
     │              └─────────────┘               │
     │                      ▲                     │
     │                      │                     │
     │              ┌───────┴───────┐             │
     └──────────────│ 用户点击卡片按钮 │─────────────┘
                    │ (callback事件)  │
                    └───────────────┘
```

## 第一步：飞书开放平台应用配置

### 1.1 创建企业自建应用

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 点击「开发者后台」→「创建企业自建应用」
3. 填写应用名称：如「SDR客户分配系统」
4. 记录 **App ID** 和 **App Secret**

### 1.2 开启机器人能力

**应用详情页 → 机器人**
- ✅ 启用机器人
- 设置机器人头像、名称、描述
- 记录 **Bot ID**（后续发送消息需要）

### 1.3 订阅卡片行为事件

**应用详情页 → 事件订阅**

| 配置项  | 值                                      |
| ---- | -------------------------------------- |
| 加密密钥 | 点击生成（用于验证请求）                           |
| 请求地址 | `https://你的域名.com/webhook/feishu-card` |
| 订阅事件 | `卡片行为回调` / `card.action.trigger`       |

### 1.4 申请必要权限

**应用详情页 → 权限管理**

搜索并添加以下权限：

| 权限名称 | 权限代码 | 用途 |
|---------|---------|------|
| 获取用户 user ID | `contact:user.id:readonly` | 获取点击人 open_id |
| 获取用户信息 | `contact:user.base:readonly` | 获取用户姓名 |
| 发送消息 | `im:message:send` | 发送卡片 |
| 更新多维表格 | `bitable:record:write` | 更新表格数据 |
| 读取多维表格 | `bitable:record:read` | 读取表格数据 |

### 1.5 发布应用版本

**应用详情页 → 版本管理与发布**
- 创建版本 → 填写更新说明
- 申请发布 → 等待企业管理员审批

## 第二步：多维表格设计

### 2.1 表格结构

**表格名称**：SDR 客户转交记录

| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| 客户姓名 | 文本 | 客户名称 |
| 客户电话 | 文本 | 联系方式 |
| 产品需求 | 文本 | 需求描述 |
| 分配销售 | 人员 | 指定跟进人（单选） |
| 分配销售ID | 文本 | 销售 open_id（用于校验） |
| 状态 | 单选 | 待确认 / 已确认 / 已跟进 / 已成交 |
| 确认时间 | 日期时间 | 点击确认按钮的时间 |
| 确认人 | 文本 | 实际确认人姓名 |
| 确认人ID | 文本 | 实际确认人 open_id |

### 2.2 获取表格信息

```bash
# 获取 base_id 和 table_id
curl -X GET "https://open.feishu.cn/open-apis/bitable/v1/apps" \
  -H "Authorization: Bearer {tenant_access_token}"
```

## 第四步：后端实现（Python Flask 示例）

### 4.1 完整代码

```python
from flask import Flask, request, jsonify
import requests
import hmac
import hashlib
import json
from datetime import datetime

app = Flask(__name__)

# ============ 配置 ============
APP_ID = "cli_xxxxxxxxxxxxxxxx"           # 你的 App ID
APP_SECRET = "xxxxxxxxxxxxxxxx"           # 你的 App Secret
ENCRYPT_KEY = "xxxxxxxxxxxxxxxx"          # 事件订阅加密密钥
BASE_ID = "xxxxxxxxxxxxxxxx"              # 多维表格 ID
TABLE_ID = "xxxxxxxxxxxxxxxx"             # 表格 ID

# ============ 工具函数 ============

def get_tenant_access_token():
    """获取 tenant_access_token"""
    url = "https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal/"
    resp = requests.post(url, json={
        "app_id": APP_ID,
        "app_secret": APP_SECRET
    })
    return resp.json().get("tenant_access_token")

def update_bitable_record(record_id, fields):
    """更新多维表格记录"""
    token = get_tenant_access_token()
    url = f"https://open.feishu.cn/open-apis/bitable/v1/apps/{BASE_ID}/tables/{TABLE_ID}/records/{record_id}"
    
    resp = requests.put(
        url,
        headers={"Authorization": f"Bearer {token}"},
        json={"fields": fields}
    )
    return resp.json()

def send_feishu_message(chat_id, msg_type="text", content=None, card=None):
    """发送飞书消息"""
    token = get_tenant_access_token()
    url = "https://open.feishu.cn/open-apis/im/v1/messages"
    
    payload = {
        "receive_id": chat_id,
        "msg_type": msg_type,
        "content": json.dumps(content) if content else json.dumps(card)
    }
    
    resp = requests.post(
        url,
        headers={"Authorization": f"Bearer {token}"},
        params={"receive_id_type": "chat_id"},
        json=payload
    )
    return resp.json()

def verify_signature(timestamp, nonce, encrypt_key, body):
    """验证飞书请求签名"""
    # 拼接字符串：timestamp + nonce + encrypt_key + body
    raw = f"{timestamp}{nonce}{encrypt_key}{body}"
    signature = hmac.new(
        encrypt_key.encode('utf-8'),
        raw.encode('utf-8'),
        hashlib.sha256
    ).hexdigest()
    return signature

# ============ 回调处理 ============

@app.route('/webhook/feishu-card', methods=['POST'])
def handle_card_callback():
    """处理卡片行为回调"""
    
    # 1. 验证请求（可选，生产环境建议开启）
    # timestamp = request.headers.get('X-Lark-Request-Timestamp')
    # nonce = request.headers.get('X-Lark-Request-Nonce')
    # signature = request.headers.get('X-Lark-Signature')
    # body = request.get_data(as_text=True)
    
    # 2. 解析回调数据
    data = request.json
    event = data.get('event', {})
    
    # 获取点击人信息
    operator = event.get('operator', {})
    clicker_open_id = operator.get('operator_id')    # 实际点击人的 open_id
    clicker_name = operator.get('name')              # 实际点击人的姓名
    
    # 获取卡片埋入的数据
    action = event.get('action', {})
    value = action.get('value', {})
    
    action_type = value.get('action')
    record_id = value.get('record_id')
    assigned_user_id = value.get('assigned_user_id')    # 指定人 open_id
    assigned_user_name = value.get('assigned_user_name')
    customer_name = value.get('customer_name')
    
    print(f"[回调] 用户 {clicker_name}({clicker_open_id}) 点击了 {action_type}")
    
    # ============ 权限校验 ============
    if clicker_open_id != assigned_user_id:
        print(f"[拒绝] 无权操作：{clicker_name} 不是指定人 {assigned_user_name}")
        return jsonify({
            "toast": {
                "type": "error",
                "content": f"❌ 无权操作！\n此任务仅分配给 {assigned_user_name}"
            },
            "card": None  # 不更新卡片
        })
    
    # ============ 处理确认操作 ============
    if action_type == "accept_customer":
        # 1. 更新多维表格
        update_fields = {
            "状态": "已确认",
            "确认时间": datetime.now().isoformat(),
            "确认人": clicker_name,
            "确认人ID": clicker_open_id
        }
        
        result = update_bitable_record(record_id, update_fields)
        print(f"[表格更新] record_id={record_id}, result={result}")
        
        # 2. 返回成功响应（更新卡片 + 提示）
        return jsonify({
            "toast": {
                "type": "success",
                "content": f"✅ 已成功确认客户 {customer_name}"
            },
            "card": {
                "schema": "2.0",
                "config": {
                    "summary": {"content": f"✅ {customer_name} - 已确认"}
                },
                "header": {
                    "template": "green",
                    "title": {"tag": "plain_text", "content": "✅ 客户已确认"},
                    "subtitle": {"tag": "plain_text", "content": f"确认人：{clicker_name} · {datetime.now().strftime('%m-%d %H:%M')}"}
                },
                "body": {
                    "direction": "vertical",
                    "elements": [
                        {
                            "tag": "markdown",
                            "content": f"**👤 客户：{customer_name}**\n\n> ✅ 状态：已确认\n> 👤 确认人：{clicker_name}\n> 🕐 时间：{datetime.now().strftime('%Y-%m-%d %H:%M:%S')}"
                        }
                    ]
                }
            }
        })
    
    # 其他操作...
    return jsonify({"toast": {"type": "info", "content": "已收到"}})

# ============ 发送卡片接口（供业务调用） ============

@app.route('/api/send-customer-card', methods=['POST'])
def send_customer_card():
    """
    发送客户分配卡片
    
    请求体：
    {
        "chat_id": "oc_xxxxxx",
        "customer_name": "张三",
        "customer_phone": "13800138000",
        "product_need": "软件订购",
        "assigned_user_id": "ou_xxxxxx",    // 指定人的 open_id
        "assigned_user_name": "李四",        // 指定人姓名
        "record_id": "rec_xxxxxx"           // 多维表格记录ID
    }
    """
    data = request.json
    
    # 构建卡片内容（使用上面第三步的模板）
    card = {
        "schema": "2.0",
        "config": {
            "summary": {"content": f"🎯 SDR转交：{data['customer_name']}"},
            "enable_forward": False
        },
        "header": {
            "template": "blue",
            "title": {"tag": "plain_text", "content": "🎯 新客户分配"},
            "subtitle": {"tag": "plain_text", "content": f"分配给：{data['assigned_user_name']}"}
        },
        "body": {
            "direction": "vertical",
            "elements": [
                {
                    "tag": "markdown",
                    "content": f"**👤 客户信息**\n\n> 姓名：{data['customer_name']}\n> 电话：{data['customer_phone']}\n> 需求：{data['product_need']}"
                },
                {"tag": "hr"},
                {
                    "tag": "markdown",
                    "content": f"⚠️ **此任务仅分配给 @{data['assigned_user_name']}，其他人请勿操作**"
                },
                {
                    "tag": "column_set",
                    "columns": [
                        {
                            "tag": "column",
                            "width": "weighted",
                            "weight": 1,
                            "elements": [
                                {
                                    "tag": "button",
                                    "text": {"tag": "plain_text", "content": "📞 联系客户"},
                                    "type": "default",
                                    "behaviors": [
                                        {
                                            "type": "open_url",
                                            "default_url": f"tel:{data['customer_phone']}"
                                        }
                                    ]
                                }
                            ]
                        },
                        {
                            "tag": "column",
                            "width": "weighted",
                            "weight": 1,
                            "elements": [
                                {
                                    "tag": "button",
                                    "text": {"tag": "plain_text", "content": "✅ 确认接收"},
                                    "type": "primary",
                                    "behaviors": [
                                        {
                                            "type": "callback",
                                            "value": {
                                                "action": "accept_customer",
                                                "record_id": data['record_id'],
                                                "assigned_user_id": data['assigned_user_id'],
                                                "assigned_user_name": data['assigned_user_name'],
                                                "customer_name": data['customer_name']
                                            }
                                        }
                                    ]
                                }
                            ]
                        }
                    ]
                }
            ]
        }
    }
    
    # 发送卡片
    result = send_feishu_message(
        chat_id=data['chat_id'],
        msg_type="interactive",
        card=card
    )
    
    return jsonify(result)

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)
```

## 🔒 安全建议

1. **验证签名**：生产环境务必验证 `X-Lark-Signature`
2. **HTTPS**：回调地址必须使用 HTTPS
3. **Token 管理**：tenant_access_token 缓存 7000 秒，不要频繁请求
4. **错误处理**：添加完善的异常捕获和日志记录
