# 飞书 API：获取群聊消息

## 流程概览

| 步骤  | 接口                                            | 目的        | 关键输出                  |
| :-: | :-------------------------------------------- | :-------- | :-------------------- |
|  1  | `POST /auth/v3/tenant_access_token/internal/` | 获取认证令牌    | `tenant_access_token` |
|  2  | `GET /im/v1/chats`                            | 获取群聊列表    | `chat_id`             |
|  3  | `GET /im/v1/chats/{chat_id}`                  | 获取群聊详情    | 群主、群名称等               |
|  4  | `GET /im/v1/chats/{chat_id}/members`          | 获取群成员（可选） | 成员列表                  |
|     |                                               |           |                       |

---

## 第 1 步：获取 tenant_access_token

**用途**：所有 API 请求的认证令牌，需放在 `Authorization: Bearer {token}` Header 中

```bash
curl -X POST https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal/ \
  -H "Content-Type: application/json" \
  -d '{
    "app_id": "cli_a90c7c4c29f8dbd2",
    "app_secret": "HWUCUR0GFObAsEUOXxwDnhOH8PSctoYv"
  }'
```

**返回**：
```json
{
  "code": 0,
  "expire": 7200,
  "msg": "ok",
  "tenant_access_token": "t-g10429lQI6SWS6AP3QFB62R2VG3O2BSFGQN4EKUY"
}
```

---

## 第 2 步：获取群聊列表

```bash
curl -X GET "https://open.feishu.cn/open-apis/im/v1/chats" \
  -H "Authorization: Bearer {tenant_access_token}" \
  -H "Content-Type: application/json"
```

**返回**：
```json
{
  "code": 0,
  "data": {
    "has_more": false,
    "items": [
      {
        "chat_id": "oc_a8246d964960b1dd3fc2697ce6d000b4",
        "name": "群聊名称",
        "owner_id": "ou_4c95ee5704fb3b992dc8cbb9e0f4dac7",
        "avatar": "https://..."
      }
    ]
  }
}
```

> 💡 提取 `chat_id` 用于后续操作

---

## 第 3 步：获取群聊详情

```bash
curl -X GET "https://open.feishu.cn/open-apis/im/v1/chats/{chat_id}" \
  -H "Authorization: Bearer {tenant_access_token}"
```

**返回**：群名称、群主 `owner_id`、群描述等

---

## 第 4 步：获取群成员（可选）

```bash
curl -X GET "https://open.feishu.cn/open-apis/im/v1/chats/{chat_id}/members" \
  -H "Authorization: Bearer {tenant_access_token}"
```

**返回**：成员列表（`user_id`, `name`, `role` 等）

---

## 快速复用

替换以下变量：
- `{app_id}` / `{app_secret}`：你的应用凭证
- `{tenant_access_token}`：第 1 步获取的令牌
- `{chat_id}`：第 2 步获取的群聊 ID
