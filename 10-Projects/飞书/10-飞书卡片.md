# 飞书卡片 2.0 开发指南

## 📋 基础规则

### Body Elements 支持的标签类型

| Tag          | 说明          | 用途                    |
| ------------ | ----------- | --------------------- |
| `div`        | 文本容器        | 显示普通文本，需要配合 `text` 属性 |
| `markdown`   | Markdown 文本 | 支持富文本格式（加粗、链接、换行等）⭐推荐 |
| `column_set` | 多列布局        | 左右/多栏并排展示             |
| `column`     | 列容器         | 放在 column_set 内       |
| `button`     | 按钮          | 需要 `behaviors` 定义点击行为 |
| `hr`         | 分割线         | 内容区块分隔                |
| `image`      | 图片          | 显示图片                  |
| `chart`      | 图表          | 显示统计图表                |

### ❌ 常见错误

| 错误用法 | 正确用法 | 说明 |
|---------|---------|------|
| `body.elements` 中直接用 `plain_text` | 用 `div` 或 `markdown` 包裹 | plain_text 只能作为子属性 |
| `button.action` | `button.behaviors` | 必须是数组格式 |
| `action` 标签 | `column_set` + `column` + `button` | 2.0 不支持 action 标签 |

## 🎨 美化技巧

### 1. 头部样式
```json
{
  "header": {
    "template": "blue",  // 可选: blue, wathet, turquoise, green, yellow, orange, red, carmine, purple, purple_v2
    "title": {
      "tag": "plain_text",
      "content": "🎯 标题"
    },
    "subtitle": {
      "tag": "plain_text",
      "content": "副标题"
    }
  }
}
```

**template 可选值**：
- `blue` - 蓝色（推荐用于通知）
- `green` - 绿色（成功/完成）
- `red` / `carmine` - 红色（警告/紧急）
- `yellow` / `orange` - 黄/橙色（提醒/待处理）
- `purple` / `purple_v2` - 紫色
- `wathet` / `turquoise` - 浅蓝/青色

### 2. 双列布局（并排展示信息）
```json
{
  "tag": "column_set",
  "columns": [
    {
      "tag": "column",
      "width": "weighted",
      "weight": 1,
      "elements": [
        {
          "tag": "markdown",
          "content": "**客户姓名**\n<font color='grey'>张三</font>"
        }
      ]
    },
    {
      "tag": "column",
      "width": "weighted",
      "weight": 1,
      "elements": [
        {
          "tag": "markdown",
          "content": "**联系电话**\n<font color='grey'>138****7890</font>"
        }
      ]
    }
  ]
}
```

### 3. Markdown 语法支持

在 `markdown` 标签的 `content` 中支持：

| 语法 | 效果 | 示例 |
|------|------|------|
| `**文字**` | **加粗** | `**重要**` |
| `<font color='grey'>文字</font>` | 灰色文字 | `<font color='grey'>次要信息</font>` |
| `> 文字` | 引用块 | `> 备注内容` |
| `\n\n` | 换行 | 两段之间空一行 |
| `\n` | 单行换行 | 行内换行 |

### 4. 按钮样式

```json
{
  "tag": "button",
  "text": {"tag": "plain_text", "content": "按钮文字"},
  "type": "primary",  // primary | default | danger
  "behaviors": [
    {
      "type": "open_url",
      "default_url": "https://example.com"
    }
  ]
}
```

**type 可选值**：
- `primary` - 🔵 蓝色（主要操作）
- `default` - ⚪ 白色（次要操作）
- `danger` - 🔴 红色（危险/确认操作）

### 5. 多按钮并排（替代 action 标签）

```json
{
  "tag": "column_set",
  "columns": [
    {
      "tag": "column",
      "width": "weighted",
      "weight": 1,
      "elements": [{ "tag": "button", "type": "primary", ... }]
    },
    {
      "tag": "column",
      "width": "weighted",
      "weight": 1,
      "elements": [{ "tag": "button", "type": "default", ... }]
    },
    {
      "tag": "column",
      "width": "weighted",
      "weight": 1,
      "elements": [{ "tag": "button", "type": "danger", ... }]
    }
  ]
}
```
