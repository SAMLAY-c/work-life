## 🎯 推荐学习路径

### 零基础入门

**阶段1：基础语法 (Week 1-4)**
1. **主教程**：JavaScript.info
   - "The JavaScript Language" 部分
   - 每天1-2个小节
2. **练习**：freeCodeCamp 或在线练习
3. **视频辅助**：B站尚硅谷（可选）

**阶段2：核心概念 (Week 5-8)**
1. **主教程**：JavaScript.info
   - "Objects: the basics"
   - "Data types"
   - "Functions"
2. **查阅**：MDN文档
3. **练习**：做小项目

**阶段3：进阶内容 (Week 9-12)**
1. **主教程**：JavaScript.info
   - "Promise, async/await"
   - "Classes"
2. **深入理解**：You Don't Know JS (选读)
3. **项目**：完整应用

## 💡 学习建议

### 如何选择教程？

**零基础**：
1. 主教程：JavaScript.info
2. 辅助：B站视频
3. 练习：freeCodeCamp

**有基础**：
1. 查阅：MDN文档
2. 深入：You Don't Know JS
3. 实战：做项目

### 学习方法

1. **看教程** → 理解概念
2. **记笔记** → Obsidian
3. **画图解** → Excalidraw
4. **写代码** → 浏览器控制台
5. **做练习** → 在线平台

### 遇到问题

1. 先查MDN文档
2. 用Google搜索
3. 让Claude解释
4. Stack Overflow
