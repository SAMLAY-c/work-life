> PARA系统中的 Resources 分类
> 用途：收藏所有AI相关的参考资料、教程、案例等

---

## 📂 文件夹结构说明

```
04-RESOURCES/AI/
├── 01-AI是什么/           ← AI基础认知、概念、论文
├── 02-AI工具使用/         ← AI工具教程和使用技巧
│   ├── 提示词技巧/        ← Prompt工程相关
│   ├── AI编程/            ← AI辅助编程
│   ├── AI自动化办公/      ← 提升办公效率
│   └── AI内容创作/        ← 文章、视频、创作
├── 03-AI变现案例/         ← AI商业化案例、副业
└── 04-行业动态/           ← 新工具、论文、新闻
```

---

## 🎯 使用指南

### 什么时候往这里放东西？

**放进这里的情况**：
- ✅ 看到一篇好的AI文章/视频 → 先收藏到 `01-INBOX`，晚上整理时移到这里
- ✅ 发现一个新的AI工具 → 记录到 `04-行业动态/`，试用后更新到 `[[03-AREAS/AI学习/工具清单.md]]`
- ✅ 学到一个提示词技巧 → 放进 `02-AI工具使用/提示词技巧/`
- ✅ 看到AI变现案例 → 放进 `03-AI变现案例/`

**不要放进这里的情况**：
- ❌ 我要做的一个AI项目 → 放进 `02-PROJECTS/`
- ❌ 我要学习的具体计划 → 放进 `03-AREAS/AI学习/`
- ❌ 临时想法 → 先放 `01-INBOX`

## 🔗 与其他文件夹的关系

```
01-INBOX (临时收藏)
    ↓ 每天整理时
04-RESOURCES/AI/ (分类存储)
    ↓ 需要使用时
03-AREAS/AI学习/ (学习计划和复盘)
    ↓ 具体实践
02-PROJECTS/ (实际项目)
```

### 具体例子

**场景1**: 看到一个很好的AI教程视频

1. 先放进 `01-INBOX` (快速捕获)
2. 晚上整理时移到 `04-RESOURCES/AI/02-AI工具使用/提示词技巧/`
3. 在 `[[03-AREAS/AI学习/我的AI学习地图.md]]` 里记录："学到了XXX技巧"
4. 如果要应用到实际项目 → 创建 `02-PROJECTS/` 项目

**场景2**: 发现一个新AI工具

1. 先放 `01-INBOX`
2. 移到 `04-RESOURCES/AI/04-行业动态/新工具-XXX.md`
3. 试用后更新 `[[03-AREAS/AI学习/工具清单.md]]`
4. 如果好用 → 加入日常工具库

## ✅ 整理原则

### 每周整理 (5-10分钟)

1. **清空**: 检查 `01-INBOX` 里是否有AI相关内容
2. **归类**: 移动到对应的子文件夹
3. **去重**: 删除重复或过时的资源
4. **更新**: 在 `03-AREAS/AI学习/` 里记录学到的东西

### 每月回顾 (30分钟)

1. **回顾**: 浏览本月收藏的资源
2. **筛选**: 标记最有价值的10个资源
3. **归档**: 3个月前的资源移到 `99-ARCHIVE/`
4. **清理**: 删除不再需要的资源

## 📝 文件命名建议

### 教程类
```
[工具/主题] 教程 - 标题.md
例如: Claude编程教程 - 从零开发网页.md
```

### 技巧类
```
[类型] 技巧 - 具体描述.md
例如: Prompt技巧 - 让AI帮你写代码.md
```

### 资讯类
```
[日期] [类型] 标题.md
例如: 2026-02-17 新工具-Cursor-2.0发布.md
```

### 案例类
```
[变现方式] 案例 - 标题.md
例如: AI写作 案例 - 月入3万的自媒体实践.md
```
