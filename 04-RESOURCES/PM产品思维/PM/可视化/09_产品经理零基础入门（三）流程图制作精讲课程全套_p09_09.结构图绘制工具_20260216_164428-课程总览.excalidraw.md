# Excalidraw Data

## Text Elements
09 结构图绘制工具 - 快捷键操作 ^title

⌨️ 通用快捷键 ^general-shortcuts

Delete键
• 删除选中元素
• 所有软件通用

Ctrl+Z / Cmd+Z
• 撤销操作
• 所有软件通用 ^universal-keys

🎯 结构图专用快捷键 ^structure-shortcuts

最核心的3个快捷键：

1. 方向键（下键）↓
   • 插入同级主题
   • 最常用

2. Enter键（回车键）↵
   • 插入子主题
   • 创建下一级结构

3. Tab键（制表键）⇥
   • 缩进/降级
   • 调整层级关系 ^core-keys

⚙️ 版本差异说明 ^version-differences

Mac系统
• Cmd + / （展开/折叠）
• Cmd + \ （其他操作）

Windows系统
• Ctrl + / （展开/折叠）
• 可能需要尝试不同组合

注意：不同版本快捷键可能略有差异
但上述3个核心快捷键保持不变 ^platform-diff

💡 使用建议 ^tips

1. 优先掌握核心3个快捷键
   - Enter：创建子主题
   - Tab：缩进/降级
   - 方向键下键：插入同级主题

2. 其他快捷键
   - 根据版本尝试不同组合
   - 菜单中查看快捷键提示
   - 遇到问题尝试Cmd/Ctrl+其他键

3. 高频操作
   - 插入同级/子主题
   - 调整层级结构
   - 展开/折叠节点 ^usage-tips

⚠️ 注意事项 ^notes

• 快捷键因软件版本而异
• 核心三个快捷键通用且高频
• 建议查看软件帮助文档
• 不确定时可通过菜单操作

💡 核心要点 ^key-points

• 通用快捷键：Delete删除、Ctrl+Z撤销
• 核心快捷键：Enter（子主题）、Tab（缩进）、下键（同级主题）
• Mac用Cmd、Windows用Ctrl作为修饰键
• 版本差异主要在展开/折叠等操作上
• 掌握核心3个快捷键即可高效绘制结构图
