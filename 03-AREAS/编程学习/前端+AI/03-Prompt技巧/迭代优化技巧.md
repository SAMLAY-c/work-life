# 迭代优化技巧

> 如何通过多轮对话让AI生成更好的代码

---

## 🔄 迭代优化的核心思想

### 不要期望一次完美

第一次生成通常是**60-70分**，通过迭代达到**90+分**

### 迭代流程

```
第1次：基本可用（描述需求）
    ↓
第2次：修复明显问题（指出错误）
    ↓
第3次：优化细节（调整样式/交互）
    ↓
第4次：性能优化（重构代码）
    ↓
第5次：完善文档（添加注释/示例）
```

---

## 📝 迭代模板

### 第1次：生成基础版本

```markdown
请创建一个[组件]：

基本需求：
- [列出核心功能]

不要过度设计，先让它能用就行。
```

### 第2次：修复问题

```markdown
上面的代码有个问题：

[问题描述具体问题]

请修复这个问题。
```

### 第3次：优化细节

```markdown
请优化上面的代码：

1. 样式调整：[具体调整]
2. 交互改进：[具体改进]
3. 边界情况：[需要处理的边界]

保持其他不变，只优化这些点。
```

### 第4次：重构代码

```markdown
请重构上面的代码：

改进点：
1. 性能：[具体优化]
2. 可读性：[具体改进]
3. 可维护性：[具体改进]

功能保持不变。
```

### 第5次：完善文档

```markdown
请为上面的代码添加：

1. JSDoc注释（每个函数）
2. TypeScript类型说明
3. 使用示例
4. 注意事项

让它成为其他开发者能直接使用的代码。
```

## 🎯 实战案例

### 案例：优化一个Table组件

#### 第1轮：基础版本

```markdown
请创建一个React Table组件：

功能：
- 接收data和columns作为props
- 渲染成表格
- 简单样式即可

先让它能用。
```

**AI输出**：基础表格，功能可用，但缺少很多细节

---

#### 第2轮：修复问题

```markdown
上面的代码有几个问题：

1. 没有处理空数据的情况（data为空时应该显示"暂无数据"）
2. 没有处理columns为空的情况
3. 没有key属性，控制台有警告

请修复这些问题。
```

**AI输出**：添加了空数据处理和key属性

---

#### 第3轮：添加功能

```markdown
请为Table组件添加功能：

1. 支持loading状态（显示loading遮罩）
2. 支持点击行（onRowClick回调）
3. 支持自定义单元格渲染（columns的render属性）

请保持现有功能，添加这些新功能。
```

**AI输出**：添加了loading、onRowClick、自定义render

---

#### 第4轮：优化性能

```markdown
请优化Table组件的性能：

1. 使用React.memo避免不必要的重渲染
2. 使用useMemo缓存计算结果
3. 使用useCallback缓存回调函数

请说明做了哪些优化，为什么这样做。
```

**AI输出**：添加了性能优化，并附上说明

---

#### 第5轮：完善文档

```markdown
请为Table组件添加完整的文档：

1. 每个Props的详细说明
2. 使用示例（至少3个不同场景）
3. 注意事项和最佳实践
4. TypeScript类型定义完整

让它成为可以直接分享给团队使用的代码。
```

**AI输出**：完整的文档和示例

## 💡 迭代技巧

### 技巧1：一次只改一件事

❌ **不好**：
```markdown
"请优化代码：
1. 修复bug
2. 改样式
3. 加功能
4. 重构
5. 加文档"
```

✅ **好**：
```markdown
"请修复上面代码的bug：
[具体描述bug]

其他部分保持不变。"
```

### 技巧2：基于上下文修改

✅ **好**：
```markdown
"基于刚才生成的Button组件，
请添加一个loading属性：
- loading时显示旋转图标
- loading时不可点击
- 保留原有样式和功能

请输出修改后的代码，并标注改动的部分。"
```

### 技巧3：对比式优化

✅ **好**：
```markdown
"当前实现的hover效果是：背景色变深

我希望的效果是：
- 背景色不变
- 添加向上移动2px的动画
- 添加阴影效果

请对比这两个效果，生成优化后的代码。"
```

### 技巧4：渐进式增强

```markdown
# Version 1: 最小可用版本

请创建一个Input组件：
- 只支持text类型
- 只支持value和onChange
- 简单样式

---

# Version 2: 添加常用功能

基于上面的Input组件，添加：
- 支持password类型（显示/隐藏）
- 支持disabled状态
- 支持placeholder
- focus时高亮

---

# Version 3: 高级功能

基于上面的Input组件，再添加：
- 字符计数器
- 清空按钮
- 错误状态提示
- 前缀/后缀图标

请输出每个版本的代码。
```

## 🚨 常见问题和解决方案

### 问题1：AI理解错了需求

**症状**：生成的代码不是你想要的

**解决方案**：
```markdown
"我刚才的需求描述可能有歧义。

我想要的是：
[重新描述需求，更具体]

而不是：
[说明AI生成的错误理解]

请重新生成代码。"
```

### 问题2：代码质量不达标

**症状**：功能对了，但代码写得很烂

**解决方案**：
```markdown
"功能是对的，但代码质量需要改进。

请优化：
1. 变量命名要语义化
2. 函数拆分要合理（单一职责）
3. 添加必要的注释
4. 遵循[具体框架]的最佳实践

请重构代码，功能保持不变。"
```

### 问题3：性能不理想

**症状**：功能对的，但有性能问题

**解决方案**：
```markdown
"功能没问题，但性能需要优化。

请分析：
1. 可能的性能瓶颈在哪里？
2. 如何优化？
3. 优化后性能能提升多少？

请输出优化后的代码，并附带性能分析。"
```

### 问题4：缺少边界处理

**症状**：正常情况能用，特殊情况会报错

**解决方案**：
```markdown
"代码在正常情况下工作良好，但需要处理边界情况：

1. data为undefined时
2. data为空数组时
3. 某个字段缺失时
4. 网络请求失败时

请添加这些边界情况的处理。"
```
