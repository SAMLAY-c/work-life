# 实践项目1：用AI生成第一个组件

> **目标**：完整体验用AI生成前端代码的流程

> **难度**：⭐⭐☆☆☆

## 🎯 项目目标

通过这个项目，你将学会：
1. 如何描述需求让AI理解
2. 如何迭代优化AI生成的代码
3. 如何记录学习日志
4. 如何复盘总结经验

---

## 📋 项目任务

### 任务：创建一个个人简介卡片组件

**需求**：
- 显示头像、姓名、职位
- 显示简介文字
- 有"关注"按钮
- hover时卡片上浮+阴影
- 使用Tailwind CSS

**技术栈**：
- React + TypeScript
- Tailwind CSS

---

## 🚀 实施步骤

### Step 1: 描述需求（3分钟）

**打开你的AI工具（Claude/ChatGPT等），输入**：

```markdown
请帮我创建一个React个人简介卡片组件：

功能需求：
1. 显示头像（圆形，100x100）
2. 显示姓名（加粗，大字号）
3. 显示职位（灰色，中等字号）
4. 显示简介文字（多行，字数不限）
5. 有"关注"按钮（蓝色，圆角）

样式需求：
- 卡片：白色背景，圆角12px，padding 24px
- 布局：垂直居中排列，间距16px
- hover效果：卡片上浮4px + 阴影
- 最大宽度：400px

技术要求：
- React函数组件 + TypeScript
- Tailwind CSS
- Props包含：name, title, bio, avatar

请生成完整代码。
```

**记录到日记** (`05-JOURNAL/2026-02-17.md`)：

```markdown
## 🕒 前端+AI 20min Log

- **时间段**：_ ~ _
- **事项**：让AI生成个人简介卡片组件（第1次）
- **类型**：前端学习
- **思路**：按照需求描述模板，详细描述需求
- **标签**：#前端AI #log #实践
```

### Step 4: 添加功能（5分钟）

**继续优化，添加新功能**：

```markdown
请为卡片组件添加功能：

1. 点击"关注"按钮后：
   - 按钮文字变成"已关注"
   - 按钮颜色变成灰色
   - 按钮不可点击

2. 添加社交链接（可选）：
   - GitHub图标链接
   - Twitter图标链接
   - 邮箱图标链接

请保持现有样式，添加这些功能。
```

**记录到日记**：

```markdown
## 🕒 前端+AI 20min Log

- **时间段**：_ ~ _
- **事项**：为卡片添加交互功能（第3次迭代）
- **类型**：前端学习
- **思路**：逐步添加功能，每次一个
- **标签**：#前端AI #log #实践
```

## 🎯 成功标准

✅ **成功**：
- 生成的代码能正常运行
- 样式基本符合预期
- 经历了2-3次迭代优化
- 记录了完整的日志和复盘

- 代码能运行，但样式有问题
- 只迭代了1次
- 日志不完整

- 没有记录日志

## 💡 项目扩展

如果这个项目太简单，可以尝试：

### 扩展1：响应式设计
```markdown
请让卡片支持响应式：
- 移动端：宽度100%，padding减小
- 桌面端：固定宽度400px

使用Tailwind的响应式类实现。
```

### 扩展2：多种样式
```markdown
请让卡片支持多种样式variant：
- default: 白色背景
- dark: 深色背景，白色文字
- gradient: 渐变背景

通过prop传入variant控制。
```

### 扩展3：动画效果
```markdown
请为卡片添加动画：
1. 初次加载时淡入
2. hover时头像放大
3. 点击关注按钮时有feedback动画

使用Framer Motion实现。
```
