## 🎯 学习建议

### 每周安排

**周一到周五**：每天30分钟
- 20分钟学习新内容
- 10分钟练习

**周六**：1小时
- 复盘本周学习
- 整理笔记
- 画Excalidraw图解

**周日**：休息或补充学习

### 学习方法

1. **看教程** → JavaScript.info对应章节
2. **做笔记** → Obsidian记录关键概念
3. **画图解** → Excalidraw可视化理解
4. **写代码** → 完成练习和小项目
5. **记日志** → 每日日记记录学习过程

### 资源使用

| 学习阶段 | 主要资源 | 辅助资源 |
|---------|---------|---------|
| 看教程 | JavaScript.info | MDN文档 |
| 理解概念 | 让Claude解释 | YouTube视频 |
| 写代码 | 浏览器控制台 | VS Code |
| 遇到问题 | Claude AI | Google搜索 |
