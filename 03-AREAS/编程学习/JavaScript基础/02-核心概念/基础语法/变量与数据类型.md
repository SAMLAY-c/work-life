## 📚 核心概念

### 什么是变量？

变量是存储数据的"容器"，就像一个有标签的盒子，可以把数据放进去，需要时再取出来。

```javascript
// 声明一个变量
let message = "Hello";  // message是变量名，"Hello"是值

// 使用变量
alert(message);  // 弹出 "Hello"
```

---

## 🔤 变量声明方式

### 1. let (现代推荐)

**特点**：
- 块级作用域
- 可以重新赋值
- 不能重复声明

```javascript
let age = 25;
age = 26;  // ✅ 可以重新赋值

let age = 30;  // ❌ 不能重复声明
```

**使用场景**：
- 需要改变值的变量
- 循环计数器
- 临时变量

---

### 2. const (常量)

**特点**：
- 块级作用域
- **不能**重新赋值
- 不能重复声明
- 声明时必须初始化

```javascript
const PI = 3.14159;
PI = 3.14;  // ❌ 不能修改

const MAX_SIZE = 100;  // ✅ 命名通常大写
```

**使用场景**：
- 不变的配置值
- 固定的参数
- 防止意外修改

---

### 3. var (旧方式，不推荐)

**特点**：
- 函数作用域（不是块级）
- 可以重复声明
- 可以重新赋值
- **有变量提升**（容易出错）

```javascript
var name = "Alice";
var name = "Bob";  // ⚠️ 不会报错，但name变成"Bob"
```

**为什么不推荐？**
- 作用域混乱
- 容易产生bug
- 现代用let/const替代

## 📊 数据类型

### 基本数据类型 (Primitive Types)

#### 1. String (字符串)

文本数据，用引号包裹：

```javascript
let str1 = "Hello";           // 双引号
let str2 = 'World';           // 单引号
let str3 = `Hello ${str2}`;   // 模板字符串（反引号）

// 字符串拼接
let greeting = str1 + " " + str2;  // "Hello World"
```

---

#### 2. Number (数字)

整数或小数：

```javascript
let integer = 42;
let float = 3.14;
let negative = -10;
let scientific = 1.5e-4;  // 科学计数法

// 特殊值
let infinity = Infinity;   // 无穷大
let notANumber = NaN;      // Not a Number
```

---

#### 3. Boolean (布尔)

只有两个值：true 或 false

```javascript
let isTrue = true;
let isFalse = false;

// 常用于条件判断
let isAdult = age >= 18;  // true或false
```

---

#### 4. Null (空值)

表示"空"或"无"：

```javascript
let empty = null;  // 明确表示"没有值"
```

---

#### 5. Undefined (未定义)

变量已声明但未赋值：

```javascript
let notDefined;
console.log(notDefined);  // undefined
```

---

### Null vs Undefined 的区别

| 特性 | null | undefined |
|------|------|-----------|
| 含义 | 故意为空 | 尚未赋值 |
| 类型 | object | undefined |
| 使用场景 | 主动清空变量 | 变量声明未赋值 |

```javascript
let name = null;         // ✅ 主动设置为空
let age;                 // ⚠️ 忘记赋值，是undefined
```

## 🎯 typeof 操作符

查看变量的类型：

```javascript
typeof "Hello"    // "string"
typeof 42         // "number"
typeof true       // "boolean"
typeof undefined  // "undefined"
typeof null       // "object" (这是历史bug)

// 用于变量
let name = "Alice";
typeof name  // "string"
```

## 💡 命名规范

### 变量命名规则

1. **只能包含**：字母、数字、$、_
2. **不能以数字开头**
3. **区分大小写**：name 和 Name 是不同变量
4. **不能用保留字**：如 let、const、if 等

### 命名建议

✅ **好的命名**：
```javascript
let userName = "Alice";
let maxCount = 100;
let isLoggedIn = true;
```

❌ **不好的命名**：
```javascript
let x = "Alice";        // 不清楚含义
let a1 = 100;           // 无意义
let DO = "something";   // 类似保留字
```

### 命名风格

**camelCase (驼峰命名)** - 推荐：
```javascript
let myVariableName = "value";
let isLoggedIn = true;
```

**常量用大写下划线**：
```javascript
const MAX_SIZE = 100;
const API_URL = "https://api.example.com";
```

## 🔍 作用域简介

### 块级作用域 (let/const)

```javascript
{
  let x = 10;
  const y = 20;
  // 在这里可以使用x和y
}
// x和y在这里无法访问 ❌
```

### 函数作用域 (var)

```javascript
function test() {
  var x = 10;
  // 函数内可以访问
}
// 函数外无法访问 ❌
```

## 📝 常见错误

### 1. 重复声明

```javascript
let name = "Alice";
let name = "Bob";  // ❌ SyntaxError

// 正确做法：
let name = "Alice";
name = "Bob";      // ✅ 重新赋值，不用let
```

---

### 2. const 未初始化

```javascript
const PI;  // ❌ SyntaxError: Missing initializer

// 正确做法：
const PI = 3.14159;  // ✅ 声明时赋值
```

---

### 3. 变量名拼写错误

```javascript
let userName = "Alice";
console.log(username);  // ❌ ReferenceError: username is not defined

// 注意：JavaScript区分大小写！
```

### 练习3：变量交换

交换两个变量的值：
```javascript
let a = 1;
let b = 2;
// 交换后：a = 2, b = 1
```

<details>
<summary>查看答案</summary>

```javascript
let a = 1;
let b = 2;
let temp = a;  // 用临时变量
a = b;
b = temp;
// 结果：a = 2, b = 1
```
</details>
