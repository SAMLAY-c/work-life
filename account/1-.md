Vercel 的免费方案被称为 **Hobby Plan**（个人爱好者计划）。

根据 Vercel 官网的最新定价策略，以下是该方案的核心免费额度与限制（**注意：这些额度仅适用于“非商业用途”的个人项目**）：

### 核心资源额度 (每月刷新)

1.  **带宽 (Bandwidth):**
    *   **100 GB / 月**。对于绝大多数个人博客、作品集或小型工具站来说，这个流量非常充裕。

2.  **构建时间 (Build Minutes):**
    *   **6,000 分钟 / 月**。这是指服务器构建你的代码所花费的总时间。
    *   *限制：* 只能单并发构建（一次只能构建一个项目，排队进行）。

3.  **Serverless Functions (无服务器函数):**
    *   **执行时间限制：** **10 秒**（这是 Hobby 版最大的限制之一，Pro 版为 60 秒或更长）。如果你的 API 处理数据很慢，可能会超时。
    *   **内存：** 1024 MB (1 GB)。
    *   **调用次数：** 虽然没有硬性明确的极低“次数”上限，但受限于带宽和执行时间。

4.  **Edge Middleware (边缘中间件):**
    *   **1,000,000 (100万) 次调用 / 月**。

5.  **存储 (Vercel Storage):**
    *   **KV (Redis):** 256 MB 存储，每月 30,000 请求。
    *   **Postgres (SQL):** 256 MB 存储，每月 60 小时计算时间，6000 万次行写入/读取。
    *   **Blob (文件存储):** 250 MB 存储，每月 500 MB 传输。

### 其他重要权益

*   **自定义域名：** **无限量**。你可以绑定任意数量的自定义域名（如 `yourname.com`），且自动配置免费的 SSL 证书 (HTTPS)。
*   **预览部署 (Preview Deployments)：** 无限次。每次 Git 推送都会生成一个唯一的预览链接。
*   **分析 (Web Analytics)：** 免费提供基础的访问统计（保留 30 天数据，每月 2500 个事件）。

### ⚠️ 关键限制（必须注意）

1.  **严格禁止商用 (Non-Commercial Only)：**
    *   Hobby 计划明确规定只能用于 **个人项目**（Personal Hobby projects）。
    *   如果你在这个账户上托管公司官网、带有盈利性质的电商网站、或接受捐赠/广告收入明显的站点，Vercel 有权封禁或要求你升级到 Pro 版（$20/月/人）。
2.  **无团队协作：**
    *   Hobby 账户只能由 **1 人**（你自己）访问。你不能邀请其他 GitHub 账号加入同一个 Vercel Team 进行协作。
3.  **技术支持：**
    *   仅提供社区支持（Community Support），没有官方邮件工单的 SLA 保证。

**总结：**
对于个人开发者、写博客、搭建演示 Demo 来说，Vercel 的免费额度是目前市面上**最慷慨且体验最好**的之一。只要你不涉及商业盈利且 API 运行时间不超过 10 秒，通常完全够用。
