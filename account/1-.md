Vercel 的免费方案被称为 **Hobby Plan**（个人爱好者计划）。

根据 Vercel 官网的最新定价策略，以下是该方案的核心免费额度与限制（**注意：这些额度仅适用于“非商业用途”的个人项目**）：

1.  **带宽 (Bandwidth):**

    *   **执行时间限制：** **10 秒**（这是 Hobby 版最大的限制之一，Pro 版为 60 秒或更长）。如果你的 API 处理数据很慢，可能会超时。

    *   **调用次数：** 虽然没有硬性明确的极低“次数”上限，但受限于带宽和执行时间。

5.  **存储 (Vercel Storage):**
    *   **KV (Redis):** 256 MB 存储，每月 30,000 请求。

### ⚠️ 关键限制（必须注意）

1.  **严格禁止商用 (Non-Commercial Only)：**
    *   Hobby 计划明确规定只能用于 **个人项目**（Personal Hobby projects）。

### 一、 快速起步：私域引流专用落地页（H5/名片）
如果你主要为了在小红书、抖音等平台引流，不需要复杂的网站，只需一个“钩子”页面或“联系方式聚合”页。

1.  **国内首选：凡科微传单 / 兔展 / MAKA**
    *   **用途：** 制作精美的H5引流页面，非常适合手机端。
    *   **免费额度：** 提供大量基础模板，可免费发布，但通常会有底部小标识（Powered by...）。
    *   **付费：** 去水印或使用高级营销功能（如表单收集、抽奖）需付费，通常几百元/年。
2.  **国际主流：Carrd**
    *   **用途：** 极简的一页式网站（One-page site），外观非常高级。
    *   **免费额度：** 一个账号可建3个站点，带 `.carrd.co` 后缀。
    *   **少量付费：** $19/年（约140人民币）即可绑定自定义域名并去除标识。
3.  **Link-in-bio 工具（多链接聚合）**
    *   **推荐：** **Linktree** (海外) 或 **小鹅通** (国内) 的基础微店页。
    *   **用途：** 把你的公众号、微信号、知识星球、产品链接集中在一个短链接里。

### 二、 长期建设：个人网站/博客
如果你想做个人IP、沉淀深度内容，需要一个更正式的网站。

1.  **Notion + Fruition/Super (最推荐)**
    *   **特点：** 像写文档一样做网站。Notion作为后台，通过工具将其转为网页。
    *   **免费方案：** Notion基础版完全免费。使用 **Fruition** (开源工具) 可以免费绑定自定义域名。
    *   **少量付费：** **Super.so** 是一键转换工具，更稳定，月费约$12。
2.  **Google Sites**
    *   **特点：** 100% 免费，无广告，界面简洁，与Google云端硬盘联动。
    *   **缺点：** 国内访问可能不稳定，需要特殊手段或主要针对海外引流。
3.  **WordPress (托管版 vs 自建)**
    *   **WordPress.com (免费版)：** 有限制，带广告，适合纯新手试手。
    *   **自建 WordPress (最强方案)：**
        *   **资源：** 下载 WordPress.org 程序（免费）。
        *   **成本：** 需购买服务器（如腾讯云/阿里云新客优惠，约38-99元/年）。

### 三、 极客方案：零成本高性能托管
如果你懂一点技术（或愿意看教程），这是性能最好、完全免费的方式。

1.  **Cloudflare Pages / Vercel**
    *   **特点：** 只要你把代码上传到 GitHub，它们就能自动帮你发布成网站。
    *   **免费额度：** **Cloudflare Pages** 提供**无限带宽**，适合大流量引流。
    *   **成本：** 0元（除域名外）。
2.  **GitHub Pages**
    *   **特点：** 程序员最爱，配合 Hexo 或 Hugo 框架可以做出极速的静态博客。

### 四、 域名与底层资源推荐（如何省钱）

做私域引流，一个好记的域名非常重要。

*   **域名购买：**
    *   **国内：** **腾讯云/阿里云**。首年 `.cn` 域名经常有特价（如8.8元/29元）。
    *   **国外：** **Spaceship** 或 **Porkbun**。新用户 `.com` 约 $7-9（50-60元），`.top` 或 `.xyz` 可能只需 $1-2。
    *   **免费域名：** 2025年比较稳的免费顶级域名有 `.us.kg` (需通过 GitHub 认证)，可以白嫖。
*   **免费图床（放图片）：** 
    *   **Cloudinary** 或 **Github + JsDelivr** (国内访问快)。
*   **免费分析工具：** 
    *   **Google Analytics** 或 **Umami** (轻量化，保护隐私)。

### 五、 2025 私域引流建议（实操细节）

1.  **钩子策略：** 网站不要只介绍自己，要放“福利”。例如：“点击领取《2025副业避坑指南》PDF”，诱导用户留下联系方式或加微信。
2.  **小红书/抖音引流：** 在个人简介（Bio）里放你的网站链接（如果平台允许）或引导用户搜索你的品牌词。
3.  **SEO引流：** 个人网站可以通过输出长内容，在百度/谷歌获取自然搜索流量，这比短视频更持久。

*   **纯引流H5：** **凡科微传单** (国内) 或 **Carrd** (国外)。
*   **完全免费且强大：** **Cloudflare Pages** + 静态网站。
