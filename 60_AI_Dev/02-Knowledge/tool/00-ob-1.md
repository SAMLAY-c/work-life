根据你提供的视频内容，这是一份详细的 **Claude Code + Obsidian 联动指南**。

这个视频主要介绍了如何通过安装两个开源项目（Skills），让 Claude Code（Anthropic 的命令行 AI 工具）直接在你的电脑上生成 Obsidian 能够识别的高级文件（如无限画布 Canvas、手绘图 Excalidraw、数据库 Bases 等）。

以下是具体的操作步骤：

### 第一步：准备工作
1.  **安装 Obsidian**：确保你已经安装了 Obsidian 笔记软件。
2.  **安装 Claude Code**：你需要有 Claude Code (CLI) 环境（这是前提，视频默认你已经配置好了 Claude Code）。
3.  **定位文件夹**：你需要知道你的 Obsidian 仓库（Vault）在电脑的哪个路径下。

---

### 第二步：安装两个核心 Skills (技能包)

视频中提到了两个项目，安装方式略有不同：

#### 1. 安装 Obsidian 官方 Skills (由 CEO 开发)
*功能：生成符合 Obsidian 语法的 Markdown（双链、Callout）、Bases（数据库）、Canvas（画布）。*

*   **操作方法**：
    在终端（Terminal）中运行 Claude Code，输入安装指令。
    （视频中提到是“添加插件市场”然后“运行命令”，通常指的是通过 MCP 或 Claude Code 的配置命令安装 `kepano/obsidian-claude-skills`）。
    *   **简单做法**：直接在 Claude Code 对话框中，让它去获取并安装 Obsidian 官方的 skills。

#### 2. 安装可视化 Skills 套装 (由博主 Axton 开发)
*功能：生成 Excalidraw（手绘风图表）、Mermaid（专业图表）、以及另一种风格的 Canvas。*

*   **操作方法（手动安装）**：
    1.  找到 Axton 开源的 Skills 仓库（通常在 GitHub 上，搜索 `Axton visualization skills`）。
    2.  下载仓库中的三个核心文件（通常是 `.md` 或 `.js` 结尾的技能定义文件）：
        *   `excalidraw`
        *   `mermaid`
        *   `canvas`
    3.  找到你电脑上 `.claude` 的隐藏配置文件夹，进入 `skills` 目录。
    4.  将下载的这 3 个文件复制进去。
    5.  **验证**：在 Claude Code 里输入 `/skills` 或问它“你现在有什么技能？”，如果列表里出现了 excalidraw 等名字，说明安装成功。

---

### 第三步：如何使用（实战指令）

安装好后，你就可以直接用自然语言指挥 Claude Code 干活了。**注意：请确保 Claude Code 的当前工作目录（cd）是你 Obsidian 笔记的根目录。**

#### 1. 生成 Obsidian 风格笔记
> **指令示例**：
> “请使用 Obsidian Markdown 技能，创建一篇关于‘个人知识管理系统’的笔记。要求使用双向链接、Callouts 提示框。”

*   **效果**：它不会生成普通的 Markdown，而是会生成带有 `[[链接]]` 和 `> [!INFO]` 这种 Obsidian 专属语法的笔记。

#### 2. 生成 Bases 数据库 (类似于 Notion 表格)
> **指令示例**：
> “创建一个 bases 文件，用于追踪我的阅读清单。包含书名、状态（想读/在读/已读）、评分字段。”

*   **效果**：生成一个 `.base` 文件，在 Obsidian 中打开就是一个交互式的数据库表格。

#### 3. 生成 Canvas (无限画布)
> **指令示例**：
> “创建一个 Canvas 文件，梳理‘人工智能发展史’，包含节点、连线和外部引用。”

*   **效果**：生成 `.canvas` 文件，在 Obsidian 中打开就是一张可视化的卡片连线图。

#### 4. 生成 Mermaid (工程图表)
> **指令示例**：
> “使用 Mermaid 技能生成一个用户登录流程图，要包含错误处理路径。”

*   **效果**：生成包含 Mermaid 代码块的笔记，Obsidian 会自动渲染成图表。

#### 5. 生成 Excalidraw (手绘风格图表) —— **重点**
> **指令示例**：
> “使用 Excalidraw 技能，画一张关于‘做饭流程’的思维导图，要是手绘风格的。”

*   **⚠️ 关键注意事项**：
    1.  Claude 会生成一个 `.excalidraw` 或包含特定代码的文件。
    2.  **必须在 Obsidian 内安装 `Excalidraw` 社区插件**。
    3.  在 Obsidian 设置 -> 第三方插件 -> 关闭安全模式 -> 搜索 `Excalidraw` -> 安装并**启用**。
    4.  如果没安装插件，你看到的只是一堆乱码或空白；安装并启用后，Obsidian 才会把它显示为漂亮的图画。

---

### 第四步：常见问题与技巧

1.  **Canvas 冲突**：
    官方 Skills 和 Axton 的 Skills 都有 `Canvas` 功能。视频建议你可以都试试，看哪个生成的逻辑更符合你的需求。通常官方的对节点连接的处理可能更原生。
2.  **Excalidraw 显示不出来**：
    如果生成后不显示，**先检查插件是否开启**。如果还是不行，截图报错界面发给 Claude Code，让它重新生成修复版（视频作者就是这么干的）。
3.  **文件位置**：
    Claude Code 生成的文件会保存在你当前的命令行目录下。在 Obsidian 中，你可以通过“打开文件夹”或刷新文件列表看到它们。

### 总结
这套玩法的核心在于：**用 Claude Code 当作你的“打字员”和“绘图员”**，你只需要动嘴（输入文字），它利用学到的 Skills 直接生成 Obsidian 能够完美运行的复杂文件格式。
