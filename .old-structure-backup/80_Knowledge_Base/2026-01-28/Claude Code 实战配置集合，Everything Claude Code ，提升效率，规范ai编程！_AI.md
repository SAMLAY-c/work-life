## 背景与核心痛点
当前AI编程面临两个关键问题：1) Claude Code等工具的使用效率未达理想状态，开发者难以充分发挥其潜力；2) 缺乏经过实战检验的标准化配置体系。该项目通过冠军团队的生产级配置集合，解决了从零构建AI开发工作流的效率瓶颈。

### 技术实现与架构
1. **多Agent架构**：包含9个专业化子代理（Planner/Architect/Code Reviewer等），采用类似微服务的设计理念
2. **技能模块化**：
   - Skills库提供前端(Lagt.jh)、后端API设计等模板
   - 10个预设斜杠命令（如`/tdd`触发测试驱动开发流程）
3. **自动化层**：
   - Honks钩子实现事件驱动（文件修改触发类型检查等）
   - 集成TypeScribe/Platter等工具链
4. **规范体系**：
   - Lulius规则引擎强制执行代码风格/安全规范
   - Git提交模板等约束

## 产品逻辑与Agent设计
1. **分工策略**：每个Agent聚焦单一职责（如Playwright代理专职E2E测试）
2. **上下文管理**：
