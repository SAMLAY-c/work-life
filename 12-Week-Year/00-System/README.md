### 常见问题

**Q：如何创建新的周记录？**
A：使用 `12w-Week-Template.md` 模板，手动选择模板文件。

**Q：如何添加新战术？**
A：直接编辑周期笔记的 tactics 数组，按照现有格式添加。

**Q：如何更新战术状态？**
A：在周期笔记中修改 tactics 数组的 status 和 completion 字段。

**Q：Dataview 查询不显示？**
A：确保 DataviewJS 已启用，检查 YAML frontmatter 格式是否正确。
