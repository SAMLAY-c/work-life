## 🎯 使用说明

### 文件夹命名规则
- `00-` 开头：收件箱/临时类
- `10-` 开头：核心业务（AI+代码）
- `20-` 开头：归档内容
- `90-` 开头：系统支撑

### 工作流程
1. **新内容** → 先放入 `00-Inbox/`
2. **整理时** → 从 Inbox 移到对应文件夹
   - AI学习/代码 → `10-AI_Dev/`
   - 完成的工作 → `20-Work_Archive/`
3. **系统文件** → 统一放在 `90-System/`

### Dataview 查询建议

#### 查看正在进行的AI项目
```dataview
TABLE without id file.link as "项目名称", priority as "优先级", due_date as "截止日期"
FROM "10-AI_Dev/01-Projects"
WHERE status = "active"
SORT priority desc
```

#### 查找Python相关代码或知识
```dataview
TABLE tags as "标签", file.folder as "位置"
FROM "10-AI_Dev"
WHERE contains(tags, "Python")
SORT file.mtime desc
LIMIT 10
```

#### 回顾锦书产品文档
```dataview
LIST
FROM "20-Work_Archive/锦书在线"
WHERE contains(file.name, "产品需求") OR contains(tags, "PRD")
```
