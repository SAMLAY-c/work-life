## 📖 什么是 MCP？

**MCP (Model Context Protocol)** 是一个开放标准协议，允许 AI 应用（如 Claude、Desktop AI 等）与外部数据源和工具进行安全、标准化的通信。

### 核心价值

| 优势 | 说明 |
|------|------|
| **标准化接口** | 统一的协议，一次开发，多处使用 |
| **安全可控** | 明确的权限管理和数据访问控制 |
| **易于集成** | 简单的客户端-服务器架构 |
| **生态丰富** | growing ecosystem of MCP servers |

### 工作原理

```
AI 应用 (Client) ←→ MCP 协议 ←→ MCP Server (数据/工具)
                              ↓
                          外部数据源/工具
```

### 第三阶段：MCP Server 开发

**📂 文件位置**：`MCP-Server开发/`

#### 学习目标
- 掌握 MCP Server 的开发流程
- 理解 MCP Server 的核心接口
- 能够创建自定义 MCP Servers

#### 核心内容

1. **Server 基础结构**
   ```typescript
   import { Server } from '@modelcontextprotocol/sdk/server/index.js';
   import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';

   const server = new Server({
     name: "my-custom-server",
     version: "1.0.0"
   }, {
     capabilities: {
       resources: {},
       tools: {},
       prompts: {}
     }
   });
   ```

2. **实现 Resources**
   ```typescript
   server.setRequestHandler(ListResourcesRequestSchema, async () => ({
     resources: [
       {
         uri: "custom://data",
         name: "My Custom Data",
         description: "Description of the resource",
         mimeType: "text/plain"
       }
     ]
   }));
   ```

3. **实现 Tools**
   ```typescript
   server.setRequestHandler(CallToolRequestSchema, async (request) => {
     if (request.params.name === "my-tool") {
       // Tool logic here
       return {
         content: [{
           type: "text",
           text: "Tool execution result"
         }]
       };
     }
   });
   ```

4. **实现 Prompts**
   ```typescript
   server.setRequestHandler(ListPromptsRequestSchema, async () => ({
     prompts: [
       {
         name: "my-prompt",
         description: "My custom prompt template",
         arguments: []
       }
     ]
   }));
   ```

5. **Server 类型**
   - **stdio Server** - 命令行通信
   - **SSE Server** - HTTP Server-Sent Events

### 第四阶段：MCP Client 开发

**📂 文件位置**：`MCP-Client开发/`

#### 学习目标
- 理解 MCP Client 的工作原理
- 掌握在自定义应用中集成 MCP
- 能够构建 AI 应用的 MCP 客户端

#### 核心内容

1. **Client 基础**
   ```typescript
   import { Client } from '@modelcontextprotocol/sdk/client/index.js';
   import { StdioClientTransport } from '@modelcontextprotocol/sdk/client/stdio.js';

   const client = new Client({
     name: "my-client",
     version: "1.0.0"
   }, {
     capabilities: {}
   });

   const transport = new StdioClientTransport({
     command: "node",
     args: ["path/to/server.js"]
   });

   await client.connect(transport);
   ```

2. **使用 Resources**
   ```typescript
   const resources = await client.listResources();
   const resource = await client.readResource({
     uri: "custom://data"
   });
   ```

3. **调用 Tools**
   ```typescript
   const result = await client.callTool({
     name: "my-tool",
     arguments: {
       param1: "value1"
     }
   });
   ```

4. **使用 Prompts**
   ```typescript
   const prompts = await client.listPrompts();
   const prompt = await client.getPrompt({
     name: "my-prompt",
     arguments: {}
   });
   ```

## ❓ 常见问题

### Q1: MCP 和其他 AI 协议有什么区别？
**A**: MCP 专为 AI 应用设计，强调安全性和标准化，支持多种数据源和工具类型。

### Q2: 可以在哪些 AI 应用中使用 MCP？
**A**: 目前主要支持 Claude，未来可能会有更多 AI 应用支持。

### Q3: MCP Server 性能如何？
**A**: stdio 模式适合本地开发，SSE 模式适合生产环境，性能取决于实现。

### Q4: 如何调试 MCP Server？
**A**:
- 使用日志输出
- 使用 Claude Code 测试
- 编写单元测试

### Q5: MCP 支持哪些编程语言？
**A**: 官方支持 TypeScript 和 Python，社区有 Go、Rust 等实现。
