## 📝 Prompt 工程

### 核心概念
**Prompt Engineering** 是设计和优化提示词的技术，用于引导 AI 模型生成更好的输出。

### 关键技巧
- **明确指令** - 清晰、具体的任务描述
- **上下文提供** - 充足的背景信息
- **示例引导** - Few-shot Learning
- **迭代优化** - 持续改进提示词

### 学习内容
- Prompt 设计模式
- 常见问题与解决方案
- 工具与框架
- 最佳实践

## 🧠 Context 管理

### 核心概念
**Context Management** 是管理 AI 模型输入上下文的技术，包括内容选择、压缩、优化等。

### 关键挑战
- **Token 限制** - 模型输入长度限制
- **信息相关性** - 选择最相关的内容
- **更新策略** - 如何更新上下文

### 学习内容
- Context 选择策略
- RAG（检索增强生成）
- Memory 系统设计
- 性能优化

## 🤖 Agent 开发

### 核心概念
**AI Agent** 是能够感知环境、做出决策并执行行动的 AI 系统。

### Agent 架构
```
用户输入
    ↓
感知 (Perception) - 理解需求
    ↓
决策 (Decision) - 规划行动
    ↓
执行 (Action) - 调用工具
    ↓
反馈 (Feedback) - 评估结果
```

### 学习内容
- Agent 框架（LangChain、AutoGPT）
- 工具调用（Tool Calling）
- 规划与推理
- 多 Agent 协作
