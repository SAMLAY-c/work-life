## 📖 什么是 Vibe Coding？

**Vibe Coding** 是一种新的编程范式，通过 AI 辅助让开发者用自然语言描述需求，由 AI 生成代码，让人专注于**意图**和**效果**而非语法细节。

> *"完全沉浸于编程的'氛围'中，忘记代码的存在"* —— Andrej Karpathy

---

## 🎯 为什么学习 Vibe Coding？

| 优势 | 说明 |
|------|------|
| **降低门槛** | 不需要精通语法也能快速构建应用 |
| **提升效率** | 从构思到原型的速度提升 10x |
| **专注价值** | 更多时间思考产品逻辑而非实现细节 |
| **持续学习** | 在实践中学习编程知识 |

## ❓ 常见问题

### Q1: 完全零基础可以学吗？
**A**: 可以！本路径专门为零基础设计，从编程思维启蒙开始。

### Q2: 需要多长时间？
**A**:
- 快速上手：2-4 周
- 系统学习：3-6 个月
- 精通进阶：1-2 年

### Q3: Vibe Coding 会取代传统编程吗？
**A**: 不会。Vibe Coding 是辅助工具，理解代码原理仍然是必要的。

### Q4: 推荐哪个 AI 编程工具？
**A**:
- 零基础推荐：v0.dev 或 Lovable
- 有编程基础推荐：Cursor
- 命令行爱好者：Claude Code
