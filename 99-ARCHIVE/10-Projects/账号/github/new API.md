你观察得很仔细，确实存在**端口显式不一致**的问题。

这通常是因为 New API 的前端页面（首页）显示的 `http://localhost:3000` 是**硬编码的默认文案**，而你实际部署时（可能是通过 Docker 或脚本）将端口映射到了 **2569**。

### 结论：请以“部署完成”的日志为准

你应该使用 **2569** 端口，而不是首页上写的 3000。

#### 1. 你的实际管理地址
请在浏览器访问：
> **http://localhost:2569**

#### 2. 你的实际 API 调用地址 (Base URL)
在其他软件（如 NextChat, LobeChat 等）中配置时，请填：
> **http://localhost:2569**
> *(或者有些软件需要填完整路径：http://localhost:2569/v1)*

---

### 为什么会这样？
*   **首页文案**：New API 的源代码中，首页默认写死是 3000 端口，因为它不知道你部署时具体映射到了哪个端口。
*   **实际运行**：你的部署脚本（或 Docker 命令）将容器内的服务映射到了宿主机的 `2569` 端口。

**下一步建议：**
按照日志提示操作即可，不用理会首页上写的 3000：
1.  访问 `http://localhost:2569`
2.  使用 `root` / `123456` 登录。
3.  **立刻修改密码**。
